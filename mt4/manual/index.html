MT4
MANUAL

Play. Modulate. Regenerate.

Techno / Ambient / Experimental. Eurorack philosophy: no presets, no permanent saving. The patch exists in the moment.

01 / START

FIRST SOUND

  1. Power the FM1 from a stable source. HOME selects a Macro voice.
  2. Turn ALGORITHM to choose the sound. Use K1–K4 to shape it.
  3. Press PLAY/STOP to run the internal clock and sequences.
  4. Open ARP for Turing, SEQ for steps, FX for processing, GLO for engines.

03 / ENGINES

SOUND + MOTION

4× MACRO

Four Plaits-based synthesis voices. Choose an algorithm and play the parameters, not a stored patch.

SEL: DECAY / EDIT LEVEL · PRE: PITCH / EDIT PITCH ENV · ALG: MODEL
K1: FREQUENCY · K2: HARMONICS · K3: TIMBRE · K4: MORPH

4× TURING

Independent evolving note/modulation loops. FREEZE holds the current pattern; REGEN creates variations.

SEL: LENGTH · PRE: FREEZE · ALG: TARGET
K1: DENSITY · K2: VARIATION · K3: SHIFT · K4: AMOUNT / DIVISION

4× SEQUENCER

Separate triggers, notes and parameter locks for each Macro. The 16 lower keys edit steps. Hold a step and turn a parameter to record a lock.

SEL: LENGTH · PRE: BANK · ALG: STEP
K1: NOTE · K2: TRIGGER · K3: MORPH LOCK · K4: MODEL LOCK

EDIT + hold SEQ clears the selected Macro sequence. This is destructive: use intentionally.

8× LFO / 4× ADSR

Two LFOs and a voice envelope for each Macro. Select destination, waveform, rate and modulation depth. ENV opens the filter and ADSR pages.

LFO: TARGET / WAVE / SYNC / RATE / AMOUNT / PHASE / SLEW. ADSR: ATTACK / DECAY / SUSTAIN / RELEASE.

4× FILTER / FX

Voice filters, resonance and drive. The FX section contains a Mixer, Reverb and Delay, with sends per voice. Effects increase CPU load.

AMBIENT / TECHNO / DRONE

AMBIENT creates four evolving musical patterns. TECHNO favours rhythm. DRONE holds continuous sound independently. The project is designed for performance, not repeatable presets.

USB MIDI / USB AUDIO

MIDI over USB only. USB audio output: 44.1 kHz. No TRS MIDI support is advertised for this GOLD build.

04 / PERFORMANCE

CPU IS THE LIMIT

MT4 is in constant tension with the FM1 processor. Four voices, modulation and effects compete for the same limited CPU budget. More sound means more load.

GLO / ENGINES lets you disable individual engines to regain headroom. The trade-off: fewer voices or fewer effects. Keeping the CPU in balance is part of the instrument.

CPU / LIVE STRATEGY

Watch the CPU meter. If audio starts to click or glitch, disable a demanding effect or Macro. Keep stable USB power. Engine switching improves headroom but does not guarantee overload-free audio.

05 / INSTALL

FLASH / USB-C

  1. Connect the powered FM1 to Chrome on Android with a USB-C data cable.
  2. On the MT4 page, download or prepare the P7.4.7 GOLD firmware. SHA-256 is checked.
  3. Run CHECK USB MIDI. An OTA identity response is mandatory; detecting a MIDI port alone is not enough.
  4. Confirm safe power and backup, start FLASH, and do not disconnect until verification completes.
RECOVERY

If the FM1 enters WL82 U-BOOT, the web flasher cannot recover it. A separate computer-based recovery process and valid backup are required. Never format the U-BOOT device.
