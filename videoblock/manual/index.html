VIDEOBLOCK / ONLINE MANUAL / BETA 3.6

DIRECT EDITING.
BLOCK LOGIC.

This manual covers the current VideoBlock workflow: video clips, Blade cuts, Blocks, multi-clip sequences, external audio sync, standalone audio editing, transient snap, IN/OUT, loop modes, project persistence and export.

01 / QUICK START

From media to sequence.

IMPORT VIDEO

Use NEW CLIP to select one or more videos. The first imported video becomes the project canvas reference for sequence export.

SCRUB

Drag directly on the preview image. VideoBlock treats the picture itself as the navigation surface.

BLADE

Place the playhead, then press BLADE. The current clip is divided into logical Blocks without destroying the original source file.

ARRANGE

Open BLOCKS, tap a Block to cue it, long-press and drag to reorder, or DELETE to remove it from the active sequence.

02 / VIDEO

Navigate on the image.

Direct scrub

Drag horizontally on the preview to move the playhead. The scrub direction follows the current inverted VideoBlock navigation model: dragging the content right moves back in time; dragging left moves forward.

Frame controls

◀ FRAME and FRAME ▶ move in frame-sized steps based on the detected frame rate of the active clip.

Blade

BLADE cuts the active video clip at the current playhead. When an existing kept Block is split, VideoBlock preserves the current sequence order and keeps previously deleted Blocks deleted.

Video loop

LOOP V loops the active Block when a Block has been cued. If no Block is active, it loops the current clip. During multi-clip SYNC PLAY, LOOP V repeats the complete Blocks sequence.

03 / BLOCKS

The edit lives here.

The Blocks page is the sequence editor. It remains in project memory instead of being rebuilt every time you return from a clip.

  • Tap a Block — cues its first frame in the preview.
  • Long press + drag — changes sequence order.
  • DELETE — removes the Block from the sequence without deleting the source media.
  • EXPORT — exports an individual Block.
  • EXPORT SEQUENCE — exports the current order as one continuous movie.
  • RESET ORDER — restores the source Blocks to the full sequence.
Adding a new clip no longer destroys the edit already prepared. New source material is appended while the current kept/deleted Block state is preserved.
04 / AUDIO SYNC

One external track under the project.

External audio is a project-level track. With one video clip, the Audio page behaves as a clip sync view. With multiple video clips, the upper waveform represents the entire current Blocks sequence while the external audio continues underneath it.

Import and sync

Use IMPORT AUDIO for the external track. AUTO SYNC can estimate an offset, while manual waveform drag and the ±1 / ±10 ms controls provide fine alignment.

SYNC PLAY

In a multi-clip project, SYNC PLAY follows the current Block order while keeping the external audio continuous instead of restarting it at every Block boundary.

Normalization

Original and external audio normalization are independent and disabled by default. Enable only the track that needs it.

05 / AUDIO EDITOR

VideoBlock can work as an audio editor.

You can import external audio even without loading a video. In audio edit mode, the waveform becomes the main editing surface.

Manual cut vs transient snap

SNAP TR OFF leaves the playhead completely free. Place it manually — including between transients — and press BLADE AUDIO to cut exactly there. With SNAP TR ON, release after scrub and VideoBlock can move the playhead to the nearest detected transient.

◀ TR and TR ▶ jump directly to the previous or next detected transient.

IN / OUT

SET IN defines the retained audio start. SET OUT defines the retained audio end. Both markers are independent of transient detection and can be placed manually. CLEAR I/O restores the full source range.

Audio loop

LOOP A continuously repeats the current IN → OUT range. This is useful for refining an attack or ending by ear before committing a cut or export.

Audio Blocks

AUDIO BLOCKS are independent from video Blocks. They can be cued, deleted from the audio edit and individually exported.

06 / PROJECTS

Save the edit, not only the files.

SAVE PROJECT writes a VideoBlock project file. LOAD PROJECT restores it. VideoBlock also keeps an internal autosave.

Project state includes source clip references, Blade positions, current Block order, deleted Blocks, external audio reference, sync offset, volumes, normalization, audio cuts, audio IN/OUT, audio/video loop state, editor position and related UI state.

Project files reference the original media. They do not embed the source videos or audio, so keep the original files available on the device.
07 / EXPORT

Video and audio exports.

Video sequence

Sequence export creates one continuous output stream. The first imported video defines the project display canvas; other source Blocks are adapted to that canvas with aspect ratio preserved when necessary.

External/project audio

Video sequence export follows the current project audio configuration, including external audio placement and the active original/external mix settings.

PCM WAV

The standalone audio editor exports PCM WAV without adding another lossy codec stage. When the source is MP3 or M4A, the result is the decoded PCM audio rather than a bit-for-bit copy of the compressed source.

08 / HELP

Support and bug reports.

For a useful bug report, include the phone model, Android version, whether the project is single-clip or multi-clip, the source media type and the shortest repeatable sequence of actions that produces the issue.
