Browser Flasher

Flasher universale per EXS MT4 sul M-VAVE FM1: seleziona il file .fwsc scaricato, verifica il dispositivo e aggiorna da Chrome via USB-C / WebMIDI.

Un solo flasher per tutte le versioni MT4: P5.8, P5.9 e successive.

Non serve più aggiornare release.json o l'SHA del sito a ogni build. Usa solo file .fwsc provenienti da una fonte fidata. L'hash locale rileva cambiamenti del file ma non ne certifica la provenienza. OTA richiede una risposta SysEx reale: se manca, la scrittura resta bloccata.
