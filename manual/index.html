01 / QUICK START

Generate, mutate and perform.

1. SOUND

Set BPM and shuffle, then shape Kick+Tom, Hats, the two Plaits-based Macro voices and the Resonator.

2. TURING

Five independent generative lanes control rhythm and pitch. Each lane can also send its Turing CV to selected voice parameters.

3. MIXER

Balance K+T, Hat, Macro A, Macro B, Resonator and Break, then use global macros, FX, 909 performance controls and sidechain.

4. BREAK

Use Slice or Texture mode, route any TTG bus through the BREAK chain, and combine it with the integrated 909 percussion bus.

TTG is designed as a live performance instrument. Most controls are intended to be moved while the transport is running. Use the per-voice RND buttons for controlled randomization; routing and Turing CV destinations are preserved.

02 / SOUND

Five voices, performance controls and Mutable-based engines.

Tempo

BPM sets the master tempo. Use minus/plus for direct changes or TAP for tap tempo. SHUF controls swing.

Kick + Tom

The kick remains TTG's dedicated kick engine. DRIVE, BF, separate Kick/Tom decay, pitch and kick PITCH ENV shape the voice. K TUR enables its dedicated Turing behavior. The 909 button switches the Tom layer to the 909-style engine; it does not replace the kick.

Hat / Perc

HH 4/4 and 16TH provide independent fixed hat layers. DECAY, DRIVE, FILTER, MORPH, DELAY and TIME SYNC shape the hat engine.

Macro A + Macro B — Plaits

Macro A and Macro B are two independent instances of the original Mutable Instruments Plaits core integrated into TTG. Each voice provides FREE / STEP pitch behavior, a SYNTH / PERC bank selector, model selection and controls for PITCH, HARMONICS, TIMBRE, MORPH, DECAY and VCA. Each Macro has its own Turing lane, modulation and mixer channel.

Resonator — Rings

The Resonator uses the Mutable Instruments Rings-style resonator core. Choose the resonator model and VOICES, then control PITCH, STRUCTURE, BRIGHTNESS, DAMPING, POSITION and VCA. T5 provides the generative strum/trigger stream.

RND + Drone

Each Sound voice has an RND button with a confirmation step. It randomizes musical parameters and that voice's dedicated Turing pattern while preserving safety-critical routing and CV target choices. DRONE switches the instrument into continuous/drone-oriented behavior where supported.

03 / MIXER

Six buses, performance FX and 909 controls.

The six mixer buses are K+T, HAT, MAC A, MAC B, RES and BRK. Each channel has level and mute. Hat, Macro A, Macro B, Resonator and Break have independent FX sends. Macro A, Macro B and Resonator also expose a bipolar mixer filter control.

Global macros

PITCH transposes the musical engine globally. CRUSH applies global bit reduction. SYNC quantizes supported performance switching to musical boundaries.

FX / Temp Performance

The global section contains DELAY, TIME, FDBK, RVB, DECAY and DROP FX. Delay can run SYNC or FREE. MACKITY adds the Airwindows-style master character stage, while SIDECHAIN controls kick-triggered ducking. TMP stores/restores a temporary performance state. HARD RESET uses a confirmation step.

909 performance row

HAT LEVARE, HAT 16TH and RIDE are independent fixed 909-style performance parts. K+T TUR mirrors the Kick+Tom Turing enable, while DECAY activates the performance decay macro.

04 / TURING

Five generative lanes, Turing CV and four LFOs.

The five lanes are T1 Kick+Tom, T2 Hats, T3 Macro A, T4 Macro B and T5 Resonator. Each lane has independent DENS, VAR, rhythmic division, scale, accent, sequence length, erase, freeze and regeneration.

DENS / VAR

Set pattern activity and mutation behavior.

SCALE / ACC

Choose the musical scale and enable per-lane accent behavior.

STEP / ERASE / NEW

Set sequence length, erase the active step behavior and regenerate the lane.

FREEZE

Hold the current generated state while the rest of TTG keeps running.

Turing CV destinations

The small CV control on each Turing lane routes its current Turing value as modulation. Pitch remains tied to TTG's automatic musical sequencing and is intentionally not exposed as a Turing CV destination.

K+T: Decay, BF, Drive, VCA. Hat: Decay, Filter, Drive, Morph, VCA. Macro A/B: Decay, Timbre, Harmonics, Morph, VCA. Resonator: Damping, Brightness, Structure, Position, VCA.

Turing CV destinations are performer-controlled and are excluded from both global and per-voice randomization.

Four LFOs

Four synchronized LFOs provide waveform, rate, target/destination and amount controls. LFO modulation and selected Turing CV can act on the same performance parameter buses. Pitch and pan remain available to LFO modulation where applicable.

Global generative controls

The lower Turing section provides root/tuning controls, the global GEN behavior and rate/amount controls, plus REC for stereo master WAV recording.

05 / BREAK

Slice, Texture, 909 and modular bus processing.

Slice mode

ENGINE enables the BREAK processor and BUS MUTE mutes its output bus. NEW, FREEZE, density, variation, step length and division control its sequence. Performance macros are PITCH, ROLL, REV and CHOP, with a shared AMT.

Texture mode

Texture mode replaces the Slice macros with granular controls for POS, SIZE, DENS, PITCH and GRAIN, plus HOLD and SYNC / FREE.

909 / Bus

The integrated 909 section provides CLOSED HAT, OPEN HAT, CRASH and RIDE. Hats have a shared level and Crash/Ride have a separate level. The fixed Hat/Ride behaviors are independent from the Turing lanes; BREAK triggering can still drive the dedicated performance behavior where configured.

Bus sources + dual filters

Route BRK, K+T, HAT, MAC A, MAC B and RES independently into the processor. LEVEL IN sets the input gain. Filters A and B each provide cutoff, resonance and HP/LP operation. LINK couples the two filter sections and BF controls the groove/body filter behavior. The output stage provides LEVEL, DELAY and RVB.

06 / SYNC + CLOCKING

Internal clock, MIDI clock and Ableton Link.

Performance SYNC

The Mixer SYNC control quantizes supported performance changes so they are applied at musical boundaries rather than immediately.

Sync source

TTG can use its internal transport, external MIDI clock or Ableton Link as the synchronization source. MIDI Clock In disables conflicting clock output behavior; Link uses the shared session beat for TTG's clock boundaries.

Ableton Link

Enable LINK from MIDI / OPTIONS to join a Link session. TTG displays Link status and peer count. START/STOP optionally follows shared transport start/stop in addition to tempo/phase synchronization.

Link and MIDI clock are separate synchronization modes; select the source that matches your setup.

07 / MIDI + OPTIONS

I/O, projects, USB routing, Link and remote control.

MIDI

The MIDI panel provides independent MIDI IN / OUT, CLOCK IN / OUT, NOTES and CC. Test Note and Test CC are available for setup. Select the MIDI device, channel and CC base, then use RESCAN / CLOSE after hardware changes. A configurable CLOCK OFFSET allows timing correction.

Project save / load

SAVE stores the current TTG project and LOAD opens a project through the Android file browser.

Audio output

Choose the Android system output or USB DIRECT 1/2 where supported. TTG reports the current direct-USB status.

Master split

Each of the six buses can be routed independently to CH1 and/or CH2. CH1 is the physical left channel and CH2 is the physical right channel, allowing independent stereo/dual-mono routing to compatible audio hardware.

Control behavior

CURVE: NORMAL / SOFT END changes the touch response. VALUES ON/OFF controls the parameter value overlay. LAT cycles the available latency profiles.

Remote controller

REMOTE CTRL enables TTG's remote-controller mode for the companion desktop/control workflow. Connection status is shown directly in the panel.

Recording

REC captures the stereo master output as a WAV file.
