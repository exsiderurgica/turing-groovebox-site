01 / QUICK START

Start with sound, then perform.

1. SOUND

Set BPM and shuffle, then shape Kick+Tom, Hats, Bass, Synth and Chords/Drone.

2. TURING

Use the five generative lanes to create, mutate, freeze and regenerate musical patterns.

3. MIXER

Balance the six buses, send selected channels to FX and use performance macros including SIDECHAIN.

4. BREAK

Use Slice or Texture mode to create performance transitions, edits and granular transformations.

TTG is designed for live interaction. Most controls are intended to be moved while the engine is running.

02 / SOUND

Voice and synthesis controls.

Tempo

BPM sets the master tempo. Use minus/plus for direct changes or TAP for tap tempo. SHUF adds rhythmic swing.

Kick + Tom

DRIVE adds saturation, BF shapes groove/body filtering, KICK PITCH sets kick tuning and PITCH ENV controls its pitch envelope. TOM VOL and TOM PITCH set the tom layer. K TUR enables the dedicated Turing behavior for the Kick+Tom lane.

Hat / Perc

8TH OFF selects the offbeat eighth-note hat behavior; the alternate state provides quarter-note on-beat behavior. 16TH is an independent sixteenth-note layer. DECAY, DRIVE, FILTER and RESO shape the hats. DELAY controls the hats delay amount and TIME SYNC selects its tempo-synced stereo ping-pong timing.

Bass / Synth / Chords

Bass and Synth provide pitch, decay, morph, drive and filter controls. Bass adds ENV and NOISE; the noise follows the bass decay VCA. Synth uses ENV as a dedicated envelope control. Chords/Drone provides two oscillator controls, attack/release, filter/resonance, morph, drive and ring modulation.

03 / MIXER

Post-performance mixing and macros.

The mixer contains six buses: K+T, HAT, BASS, SYN, CHRD and BRK. Each strip has a level and mute control. Hats, Bass, Synth, Chords and Break also have independent FX sends.

Global macros

PITCH and CRUSH are global performance controls. SYNC quantizes supported performance changes so they occur on musical boundaries.

FX / Temp Performance

DELAY, TIME and FDBK control the global delay. RVB and DECAY control reverb. DELAY SYNC locks the delay timing to tempo. BEAT REP, division and REP MIX control beat repeat. DROP FX is a continuous transition macro and TMP stores/restores a temporary performance state.

Sidechain

SIDECHAIN is a kick-triggered ducking macro. At zero it is a true bypass. Increasing the amount progressively ducks Tom, Hats, Bass, Synth, Chords, Break and FX returns while the Kick remains at full level. The envelope follows the actual kick trigger, keeping the pumping musically locked to the kick pattern.

04 / TURING

Five generative lanes + four synced LFOs.

The five Turing lanes are T1 Kick+Tom, T2 Hats, T3 Bass, T4 Synth and T5 Chords. Each lane has independent density, variation, rhythmic division, step length, freeze and regeneration.

DENS

Controls how active the generated lane is.

VAR

Changes pattern variation/probability behavior.

STEP

Sets the active sequence length, from short loops to longer cycles.

FREEZE / NEW

FREEZE holds the current state; NEW regenerates the lane.

Four LFOs

Each LFO has waveform, synced rate, target, destination and amount. Long rates include 1 BAR, 2 BAR and 4 BAR. GEN controls global generative evolution.

05 / BREAK

Slice and granular Texture modes.

Slice mode

ENGINE enables the Break processor and BUS MUTE removes the Break bus. NEW, FREEZE, density, variation, step length and rhythmic division control its sequencing. The performance macros are PITCH, ROLL, REV and CHOP, with a shared amount control.

Texture mode

Texture mode adds granular controls for POS, SIZE, DENS, PITCH and GRAIN, plus HOLD and FREE. The lower routing section is shared with Slice mode: source buses, input level, BF, drive, filter, resonance, bipolar control, output level, delay and reverb.

06 / SYNC

Quantized performance switching.

When SYNC is enabled, supported performance actions are aligned to a musical quantization boundary instead of being executed immediately.

The SYNC control stays visibly engaged. A clock indicator marks the quantization point, while a separate pending outline is used for controls waiting for the next synchronized state change. This keeps the clock feedback separate from the actual ON/OFF state of each control.

Audio state and visual pending state are deliberately separated to avoid ambiguous flashing or intermediate button states.

07 / MIDI + RECORDING

External clock, MIDI output and WAV capture.

The MIDI panel provides independent CLOCK IN, CLOCK OUT, NOTES OUT and CC OUT. Clock In follows an external MIDI clock; Clock Out sends the internal clock at 24 PPQN. Notes and CC can be enabled independently. Use RESCAN / CLOSE after connecting or changing a MIDI device.

REC records the stereo master output as a WAV file.

Recovery

HARD RESET restarts the application core if the performance state becomes abnormal.
