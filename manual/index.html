01 / QUICK START

Generate, mutate, sample and perform.

1. SOUND

Set BPM and shuffle, then shape Kick+Tom, Hats, Macro A, Macro B and the Resonator. K09 and T09 provide alternative kick/tom models.

2. TURING

Five independent generative lanes control rhythm and pitch. Shift each pattern by one step with - / + and return it to zero with SHIFT.

3. MIXER

Balance K+T, Hat, Macro A, Macro B, Resonator and Samples. Use channel filters, mutes, global macros and performance FX.

4. SAMPLES

Import a sample or loop, edit it from the waveform, generate rhythm-safe slices, then route material through VCF and Grain FX.

TTG is built for live performance. Most controls can be changed while the transport is running. The B126 Slice Macro is deterministic: AMT changes how many prepared Roll/Chop events are active instead of creating random timing events on every step.

02 / SOUND

Five voices, new drum models and performance controls.

Tempo

BPM sets the master tempo. Use minus/plus for direct changes or TAP for tap tempo. SHUF controls swing.

Kick + Tom

DRIVE and PUNCH shape the K+T bus. Separate KICK DECAY, TOM DECAY, pitch controls and kick PITCH ENV shape the two voices. Beta 6 adds K09 and T09 alternative kick/tom models. Kick and Tom decay now use the same perceptual response curve as the Hat decay control. K TUR enables the dedicated Kick+Tom Turing behavior.

Hat / Perc

The Hat engine provides fixed 4/4/offbeat behavior plus the independent 16TH layer. DECAY, DRIVE, OS LEV, MORPH, DELAY and TIME SYNC control the percussion section. Setting the Hat drive fully to zero closes the Hat engine.

Macro A + Macro B

Macro A and Macro B are independent macro oscillators with STEP / FREE pitch behavior, SYNTH / PERC banks and model selection. The active controls are PITCH, HARMONICS, TIMBRE, MORPH, DECAY and VCA. FM1, FM2 and FM3 are removed from the selectable/randomized model banks in Beta 6.

Resonator

The Resonator is based on the Mutable Instruments Rings resonator architecture. Choose the resonator model and VOICES, then control PITCH, STRUCTURE, BRIGHTNESS, DAMPING, POSITION and VCA. The available extended models include the String + Reverb variant.

RND + Drone

Each Sound voice has an RND control with confirmation. It randomizes musical parameters and the voice's dedicated Turing material while preserving protected routing choices. DRONE switches supported engines into continuous/drone-oriented behavior.

03 / MIXER

Six buses, bipolar filters and performance FX.

The six mixer buses are K+T, HAT, MAC A, MAC B, RES and SAMPLES. Every channel has level and mute. The K+T strip also provides KICK M, which mutes the kick without muting the tom.

Channel filtering

Hat, Macro A, Macro B, Resonator and Samples provide a bipolar mixer filter. Center is bypass, the left side moves toward low-pass filtering and the right side toward high-pass filtering. Beta 6 includes smoothing and de-click work across these filter paths.

Global macros

PITCH transposes the musical engine globally. CRUSH applies global bit reduction. SYNC quantizes supported performance switching to musical boundaries.

FX / Temp Performance

The global section contains DELAY, TIME, FDBK, RVB, DECAY and DROP FX. Delay can run synchronized or free. MACKITY adds master character, while SIDECHAIN controls kick-triggered ducking. TMP stores/restores a temporary performance state and HARD RESET uses a confirmation step.

04 / TURING

Five generative lanes, pattern shift, Turing CV and four LFOs.

The five lanes are T1 Kick+Tom, T2 Hats, T3 Macro A, T4 Macro B and T5 Resonator. Each lane has independent DENS, VAR, rhythmic division, scale, accent, sequence length, erase, freeze and regeneration.

- / SHIFT / +

Rotate the current Turing DNA one step backward or forward. Tap SHIFT to reset the lane shift to zero.

DENS / VAR

Set pattern activity and mutation behavior without replacing the entire lane.

SCALE / ACC / STEP

Choose the musical scale, accent behavior and sequence length.

FREEZE / NEW

Freeze the current generated state or build a new lane pattern.

Turing CV destinations

The small CV control routes the current Turing value as modulation to supported voice parameters. Pitch remains handled by TTG's musical sequencing and is not exposed as a Turing CV target. CV target choices are excluded from global and per-voice randomization.

Four LFOs

Four LFO sections provide waveform, synchronized/free rate, target, destination and amount controls. Current destinations include voice parameters, VCA/pan where supported, and Oneshot pitch targets.

Global generative controls

The lower section provides root/tuning, global GEN behavior and global rate/amount controls. REC captures the stereo master output as WAV.

05 / SAMPLES

Sample player, Slice engine, Oneshot voices, VCF and Grain FX.

Source: Slice / Sample

The page has two source workflows. SLICE is the tempo-oriented loop slicer. SAMPLE is the independent sample player/editor. SLICE ON enables the slicing layer and SAMPLES M mutes the Samples bus.

Sample mode

Use IMPORT to load audio and PLAY / STOP to audition it. The waveform displays editable IN and OUT points so the useful region can be trimmed directly. PITCH changes playback pitch/rate and VOLUME sets the sample level.

Slice mode

LOAD LOOP imports the slicing source. TTG displays the source BPM and provides /2 and x2 corrections when BPM detection lands on a half/double value. NEW, FREEZE, DENS, VAR, STEP and division define the repeating slice pattern.

Rhythm-safe Slice Macro

Beta 6 replaces the older Pitch/Roll/Reverse/Chop random macro with a deterministic MACRO based only on rhythm-safe Roll + Chop events. There is no Macro Pitch and no Macro Reverse. The macro pattern is generated once; AMT reveals more or fewer prepared events instead of regenerating timing on every step. SLICE VOL sets its level.

Oneshot / Direct

CLOSED HAT, OPEN HAT, CRASH and RIDE are direct percussion voices. Each now has its own V (volume) and P (pitch) control. Their pitch parameters can also be addressed by the LFO system.

Bus Sources

The routing row selects which performance sources feed the Samples processing section: SLICE, K+T, HAT, MAC A, MAC B and RES. The processing layout is split into a left VCF module and a right GRAIN FX module.

VCF

The VCF has independent BYPASS, LEVEL IN, CUT, RES and PUNCH, plus HP / LP mode selection. The VCF is intentionally the left module - it is not Grain FX.

Grain FX

The right module is the Clouds-based GRAIN FX processor. It provides independent BYPASS and LEVEL IN, plus POS, DENS, SIZE, TEXT, PITCH, WET, STEREO, FDBK, REVERB and FREEZE. It is designed for granular texture, movement and atmosphere without requiring the Slice engine to be active.

06 / SYNC + CLOCKING

Internal clock, MIDI clock and Ableton Link.

Performance SYNC

The Mixer SYNC control quantizes supported performance changes so they are applied at musical boundaries rather than immediately.

Sync source

TTG can use its internal transport, external MIDI clock or Ableton Link. MIDI Clock In disables conflicting clock-output behavior; Link uses the shared session beat for TTG's clock boundaries.

Ableton Link

Enable LINK from MIDI / OPTIONS to join a Link session. TTG displays Link status and peer count. START/STOP can optionally follow shared transport in addition to tempo/phase synchronization.

07 / MIDI + OPTIONS

I/O, projects, USB routing, Link and remote control.

MIDI

The MIDI panel provides independent MIDI IN / OUT, CLOCK IN / OUT, NOTES and CC. Select device, channel and CC base, then use RESCAN / CLOSE after hardware changes. A configurable CLOCK OFFSET provides timing correction.

Project save / load

SAVE stores the current TTG project and LOAD opens a project through the Android file browser.

Audio output

SYS cycles Android system outputs and can select a connected USB DAC when Android exposes it as an output device. USB DIRECT 1/2 is TTG's separate direct-USB stereo path and should only be used when that hardware path is desired.

Master split

Each of the six buses can be routed independently to CH1 and/or CH2. CH1 is physical left and CH2 is physical right, enabling stereo or dual-mono routing to compatible hardware.

Control behavior

CURVE: NORMAL / SOFT END changes touch response. VALUES ON/OFF controls the parameter overlay. LAT cycles latency profiles.

Remote + recording

REMOTE CTRL enables the companion remote-controller workflow. REC captures the stereo master output as a WAV file.
